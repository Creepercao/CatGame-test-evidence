## USB 安装解除与采样

用户开启 USB 安装和 USB 调试安全设置后，普通 APK 与独立 `.perf` APK 均安装成功。普通 APK 首次启动显示主菜单，原始横屏为 2712×1220，窗口报告左侧挖孔安全区 88 像素。主菜单截图人工检查中文标题、按钮、插画和左右边缘可见。该判断来自 `initial-menu.png` 与窗口信息。

性能包单猫和 100 猫各做 3 秒探针。单猫采到 183 帧，100 猫采到 182 帧，连续性和有效 PSS 检查均通过；P95 分别为 16.546 和 16.552 ms，探针不作参考预算判定。原始帧 CSV、结果 JSON 和内存文本分别在 `perf-probe-01/01-single/` 与 `01-hundred/`。随后以同一 APK 启动单猫、100 猫各三轮 60 秒正式采样，过程中停止手机截图与触摸。

开始完整采样时手机处于 USB 充电状态，电量 49%、电池温度 32.5℃。这些值只记录本轮采样环境，耗电专项需要另设条件。

## 原生尺寸功能用例

新增 `PhoneGame.py`、`phone_smoke.robot` 与 `phone_lifecycle.robot`。坐标依据当前手机 2712×1220 和实际左侧安全区 88 像素计算，当前实现针对这台手机布局。普通界面复用既有截图裁片进行像素重采样，真机独立门限为 RGB 平均误差 12；数字和暂停标题采用人工核对的原生裁片，猫数还要求与其他猫数模板至少相差 3。原模拟器门限 2.5 保留。

用例覆盖新档、引导、自然收益购买、成就 CG、后台热恢复、强停冷启动、商店滚动、暂停设置、成就与图鉴页、锁屏解锁及无默认网络冷启动。执行时保留 Robot XML、逐步截图和输入/PID 日志，再人工复核关键端点。飞行模式和 Wi-Fi 状态在用例退出时恢复。

## 当前发现与后续

在 2712×1220 房间截图中，右侧露出约 156 像素宽的相机背景色条，已记录为超宽屏适配缺陷。主菜单和各弹窗内容当前可见，房间背景铺满仍需修复。上次模拟器购买偶发失败在本次手机流程未复现，原失败继续保留。

当前包固定 LandscapeLeft，验收覆盖该方向的挖孔及手势导航，不把另一握持方向或其他手机型号算作通过。短时挂机观察另外记录。USB 充电条件下未进行耗电专项，也未据短周期 PSS 判定泄漏。

## 100 猫短时挂机

额外一次 100 猫帧采样通过参考预算后，继续保持该场景 300 秒。实际观察 301.796 秒，PID 32583 始终相同，每分钟核对仍在前台。游戏时间推进 300.232 秒，拥有的 440 只猫未变，对应场景可见上限 100。五次系统 PSS 为 256764、258158、259457、260553、261684 KiB。采样的 60 秒帧时间窗口与后续挂机内存查询分开记录。

首个可读性预检发现 `run-as` 无法读 QA 外部存储，尚未开始挂机。改用手机已允许的 ADB 只读外部存储路径后执行成功。全过程无 root，无截图或触摸干预挂机。观察结束后停止 QA 进程。原始证据在 `idle-01/01-hundred/idle-result.json`、`idle-*-meminfo.txt` 和 CSV。该观察不等于数小时稳定性验收。

当前唯一确认的游戏显示缺陷是超宽屏房间右侧背景色边。首轮测试的竖屏过渡帧、缩放模板误判以及首次摸猫 CG 前置遗漏均保留原失败，并通过后续用例修订复验。普通版当前保留本次正常游玩生成的三猫、摸猫计数 2 的测试档，未向普通版写入测试余额。

测试源码提交为 `56ca70d`，使用用户的 Git 身份。收尾时独立核对了手机上普通 APK 的 SHA-256 与本地候选一致。手机飞行模式恢复为 0、Wi-Fi 恢复为 1。两个测试应用进程和本轮 Appium 服务已关闭，安装包保留在手机上。MuMu 未参与本轮真机测试。
