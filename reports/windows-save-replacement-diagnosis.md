# Windows 存档替换失败排查

2026-11-14，承接 TODO M16。目标是确定压力测试中 Win32 1175 的触发层次和安全恢复条件，不以新通过记录覆盖此前失败。当前 Android 预览 APK、Windows 发行包和生产保存代码均未修改。

## 原始游戏路径复现

在没有编辑器运行时，以 Unity CLI 1.0.0 / Unity 2022.3.21f1 运行完整 EditMode，最多计划三轮，首次失败即停止。环境 TEMP/TMP 使用 `Build/Android/build-temp`，Editor 存档隔离到 `Build/SaveDiagnosis/editor-save`，`CATGAME_SAVE_FAILURE_ROOT` 指向独立诊断目录。

`Build/SaveDiagnosis/repeat-01/EditMode-1.xml` 为 61/62，唯一失败为原千次存档压力用例第 969 轮，HResult=0x80070497。Unity 进程退出 2、CLI 退出 8，未将 XML 和进程退出码混为同一层。随后两轮未执行，不计通过。

异常时复制的现场：主档 clicks=968，备份 clicks=967，临时文件 clicks=969。三个文件均可解析。它证明这一次替换失败保留了上一份已提交主档，不证明所有 I/O 故障均能保留数据。`save.bad.json` 是该用例第 499 轮主动注入的损坏数据，也保留在现场副本中。

## 假设与 Win32 最小对照

此前排序：其他用例/顺序干扰；已有备份的替换；Windows 短暂占用或系统文件操作条件。未给具体占用进程下结论。

最小探针只用 Python ctypes 直接调用 `ReplaceFileW`，循环写 3 KB 合成 JSON。每轮使用新目录，不加载 Unity、不调用游戏方法，分为有备份与无备份两种。每次成功后读回字节并检查临时文件已移除。

| 执行环境 | 三轮有备份完成数 | 三轮无备份完成数 | 结果 |
|---|---|---|---|
| 沙箱初探 | 36、194、675 | 76、95、1000 | 五组遭遇 1175、一组完整 1000 |
| 与 Unity 相同的普通用户环境 | 169、298、237 | 237、290、300 | 六组均遭遇 1175 |

所有失败均核对主档仍为上一份已提交字节、临时文件仍为本轮待提交字节。原始输出分别为 `native-probe-01.log`、`native-probe-unsandboxed-01.log`，对应目录下保留 `results.json` 和文件。该实验排除了“必须依赖 Unity”及“必须有备份”的条件；它不证明每一例游戏失败都由同一外部进程引起，尚未定位哪个 Windows 组件或进程导致 1175。

## 有限重试诊断

新增 `tools/qa/windows_replace_probe.py`，默认不重试且失败退出 1。另用 `--retries 3 --delay-ms 10` 做诊断：只对 1175、且主档和临时文件字节均保持的条件最多重试三次，所有错误事件仍逐项记录，成功后核对备份字节等于上一份主档。不是把每轮失败无条件改为通过，也没有把该策略加入游戏。

执行命令：`python tools/qa/windows_replace_probe.py --output Build/SaveDiagnosis/native-retry-01 --retries 3`。结果按每组实际完成数、错误事件数、是否恢复分别统计；未执行到的组不计入。

### 有限重试的实际结果

native-retry-01 六组各完成 1000 次，共 6000 次成功提交，退出 0。保留的 1175 事件数依次为 1/1/2/1/5/1，共 11 次；均在首次调用失败后等待 10ms、第一次重试成功（错误事件 attempt 均为 0）。每个错误均验证主档和临时文件原字节不变，成功后备份也按正常链条核验。没有删除这些错误或称它们从未发生。

为保持可比性，随后同一工具以 --retries 0 运行 native-strict-02，失败时返回 1，而不是旧一次性探针的脚本遍历退出 0。旧探针结果必须按每组 completed/error 解读，不能把进程 0 计作六组保存通过。新工具 source 已纳入私有工程 Git；生产游戏保存代码和发行包本轮仍未改变。

同工具无重试对照 native-strict-02 已结束，六组完成数依次 328/527/117/1000/143/140，五组记录 1175、一组完整通过，整体退出 1。说明仍有间歇性，不能将少量自然通过当作根因消失。工具提交 a242ae1，作者 Creepercao。原有游戏存档代码和发行版未变。
